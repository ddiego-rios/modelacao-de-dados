# Modelação de Dados

Projeto desenvolvido em aula no âmbito da formação de **Modelação de Dados**.

Este repositório reúne exercícios práticos de bases de dados, SQL e modelação desenvolvidos durante as aulas, incluindo scripts e modelos do MySQL Workbench.

## Sobre o autor

Sou aluno e estudante de **Análise de Dados (IEFP)**, com interesse em Python, SQL, Power BI, ETL, modelação, estatística aplicada e Business Intelligence.

## Conteúdo

O repositório inclui scripts SQL, exercícios de inserção e alteração de dados e modelos relacionais desenvolvidos ao longo da unidade de formação.
